# Arcane | Fan Page

## Sobre o projeto

Esta é uma **fan page inspirada na série Arcane**, criada exclusivamente para fins educacionais.

O projeto foi desenvolvido como uma forma de colocar em prática os conhecimentos adquiridos durante meus estudos de **HTML5 e CSS3**, explorando estruturação de páginas, estilização, fontes, imagens e organização de conteúdo.

### Objetivos

* Praticar HTML5 e CSS3;
* Aplicar os conhecimentos aprendidos no curso em um projeto próprio;
* Desenvolver uma página visualmente inspirada em uma obra que gosto;
* Aprimorar minhas habilidades em desenvolvimento web.

## Aviso

Este projeto **não possui finalidade comercial** e não possui vínculo oficial com a Riot Games, Netflix ou qualquer outra empresa relacionada à produção de *Arcane*.

*Arcane*, seus personagens, nomes, imagens, logos e demais elementos relacionados à obra pertencem aos seus respectivos detentores de direitos.

Esta página foi criada por um fã **exclusivamente para estudo e prática de desenvolvimento web**, sem intenção de comercializar ou reivindicar a propriedade desses elementos.

## Tecnologias utilizadas

* HTML5
* CSS3
